## 钱包始终显示0的根因修复（v4 — 双重包装 bug）
- **根因**：`WalletSkill.getBalance` 返回 `{ success: true, data: WalletBalance }`，`BaseSkill.execute` 又包一层 `{ success: true, data: { success, data } }` → `result.data.gameCoins` = undefined → 0
- **修复 `WalletSkill.ts`**：所有 action 直接返回数据（不包 `{ success, data }`），spend 余额不足时 throw Error
  - `getBalance` → 返回 `WalletBalance`（加日志）
  - `recharge/spend/adjustBalance` → 返回 `WalletBalance`
  - `getTransactions` → 返回 `WalletTransaction[]`
  - `getStats` → 返回 `WalletStats`
- **修复 `useWallet.ts`**：防御性解包 `raw?.data ?? raw`，兼容旧的双重包装和新的单层
- **修复 `Login.tsx`**：测试账号登录时同时写入 `allinone_user` 键（AuthProvider 读此键），避免 CloudBase 状态监听覆盖 React state

## 商店钱包支付不通的根因修复（v5 — userId context 缺失）
- **根因**：`GameStore.tsx`、`GamePlay.tsx`、`voucherItemService.ts`、`walletCompat.ts` 中所有 `skillGateway.execute('wallet', ...)` 调用都没传 userId context → WalletSkill 默认用 `'anonymous'` 用户 → 读不到余额、扣不了款
- **修复**：
  - `GameStore.tsx`：添加 `getSkillContext()` 辅助函数（从 `currentUser` 取 uid/id），所有 execute 调用传入 context；`loadBalance()` 加防御性解包
  - `GamePlay.tsx`：`loadBalance()` 传入 `{ userId, sessionId }` context + 防御性解包
  - `voucherItemService.ts`：`purchaseItemVoucher` 中 wallet spend 调用传入 `{ userId: request.userId, sessionId: 'web' }`，`reason` 参数名改为 `description`
  - `walletCompat.ts`：添加 `getCurrentUserId()`（从 localStorage 读 `allinone_user`/`currentUser`）和 `getSkillContext()`，所有 13 处 execute 调用传入 context；`getBalance` 返回值加防御性解包
- 4 文件 0 新增 lint 错误，vite build 通过
