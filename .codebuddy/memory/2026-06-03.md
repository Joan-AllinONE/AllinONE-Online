## Phase D: 凭证二分法 (道具/A币凭证分离) + 运行时错误修复
- **问题**: 道具凭证(ITEM)的 denomination 被钱包误计入A币余额；道具凭证无法上架（`'ITEM' !== 'item'` 大小写 bug）
- **解决方案**: 在 voucher-system/types.ts 新增 `isCurrencyVoucher()` / `isItemVoucher()` 类型守卫
- 修改 6 个文件:
  1. `voucher-system/types.ts` — 新增 `CURRENCY_SOURCE_TYPES` 常量和两个类型守卫函数
  2. `services/voucherPaymentService.ts` — payWithVoucher/getUserVoucherBalance/getUserVouchers 3个方法增加 isCurrencyVoucher 过滤
  3. `services/marketplaceService.ts` — validateForListing 修复字符串 `'ITEM'` → 枚举 `VoucherSourceType.ITEM`; 修复 `import type` → `import`（枚举需运行时存在）
  4. `components/Marketplace.tsx` — 道具凭证过滤器修复枚举（同上）
  5. `skills/compat/walletCompat.ts` — distributeACoins 显式设置 sourceType=VoucherSourceType.INSTANT
  6. `hooks/useWallet.ts` — 注释更新说明仅计A币类凭证
- **运行时修复**: marketplaceService.ts 的 `import type { VoucherSourceType }` 导致 Vite 打包剥离枚举，报 VoucherSourceType is not defined → 改为 `import { VoucherSourceType }` 值导入
- 所有修改文件 0 lint 错误
