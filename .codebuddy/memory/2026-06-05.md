## 游戏商账户体系实现

### 背景
玩家在商店购买道具时，用于支付的凭证被转移到 `SYSTEM` 账户（黑洞），而非游戏开发者账户。用户指出应有游戏商账户，在发布游戏时自动创建。

### 实施方案（5个阶段）

**Phase 1: 数据模型**
- 新建 `src/types/gameDeveloper.ts` — GameDeveloperAccount、GameDeveloperOverview、GameItemSaleStat、DeveloperRevenueTransaction 等类型
- 账户 ID 命名规范：`game-{gameId}`
- 新增系统账户常量：`PLATFORM_POOL`、`PLATFORM_TREASURY`、`SYSTEM`

**Phase 2: 发布时自动建账**
- 新建 `src/services/gameDeveloperService.ts` — 开发者账户 CRUD + 收入记录 + 每日结算 + 提现管理
- `PublishedGame` 新增字段：`publisherId`、`publisherName`、`revenueSharePercent`
- `savePublishedGame()` 自动调用 `gameDeveloperService.ensureAccount()`
- `PublishingPipeline.stepRegisterPlatform()` 传入发布者信息
- `PublishingConfig` 和 `StandardGameConfig.monetization` 新增 `revenueSharePercent`

**Phase 3: 购买流向改造**
- `GameStore.handlePurchase()` — voucher 支付 `toUserId: 'SYSTEM'` → `getGameDeveloperAccountId(gameId)`
- `voucherItemService.purchaseItemVoucher()` — 同上，`PLATFORM_POOL_ID` → 游戏商账户
- 找零凭证由开发者账户铸造
- 调用 `gameDeveloperService.recordPurchaseRevenue()` 记录收入

**Phase 4: 开发者面板**
- 新建 `src/components/GameDeveloperPanel.tsx`
- 显示：累计收入、可提现余额、待结算分成、已结算分成、道具销售统计、收入记录
- 支持手动触发每日结算
- 入口：GameStore 头部"开发者面板"按钮（琥珀色渐变）
- 结算改为每日（原方案为每月）

**Phase 5: 平台管理端**
- `PlatformAdmin` 新增"游戏商总览" Tab
- 显示所有游戏商账户表格：游戏名、发布者、累计收入、可用余额、待结算、分成%
- 支持修改分成比例、批量每日结算

**存量兼容**
- `main.tsx` 启动时遍历所有已发布游戏自动补建开发者账户
- 启动时调用 `gameDeveloperService.checkAndSettle()` 执行每日结算

## Bug 修复：凭证支付余额不足时的静默降级问题

### 问题（v2 修正）
用户在 GameStore 选择"凭证支付"，凭证余额为 0 或不足时，系统静默降级扣游戏币 / 未给出明确提示。

### 根因
- `voucherItemService.ts` L341：获取用户凭证时未用 `isCurrencyVoucher()` 过滤，可能混入道具凭证干扰余额计算
- 余额检查散落在凑单逻辑之后，错误提示不够明确（只有"余额不足"三个字）

### 修复（v2）
- `voucherItemService.ts`：
  - 导入 `isCurrencyVoucher` 类型守卫
  - 凭证支付分支新增**提前余额检查**：先用 `isCurrencyVoucher` 过滤仅取 A币类凭证，计算 `currentBalance`
  - 余额为 0：提示"余额为 0，请获取凭证或切换游戏币支付"
  - 余额不足：提示"当前 X A币，需要 Y A币，还差 Z A币"
  - 三路分支明确：凭证支付 / 钱包支付 / 不支持凭证的错误提示
- `VoucherSkill.ts`：默认 `acceptVoucher: false` → `true`（顺带改进）

## CloudBase 数据库迁移 — 全业务 localStorage → 双写模式

### 背景

### 迁移策略

| 新建 | `src/services/dualWrite.ts` | 双写工具（cloudWrite/cloudRead/cloudDelete/createDualStore） |
