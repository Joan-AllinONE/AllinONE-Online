## Match3Game 道具通信修复 — Mode B 极简方案
- **根因**：PlatformBridge 通过 `fetch('/api/skills/...')` 调用不存在的 HTTP 端点 → 道具库存始终为 0
- **方案**：参考 ZUMA (`index.html`) 的 Mode B 模式，废弃 fetch 桥接，监听平台 SDK 注入的 `allinone:item-redeemed` CustomEvent
- **修改文件**：`AllinONE Online/Match3Game.html`
- **删除**：fetch-based PlatformBridge (callSkill/getPowerUpCounts/consumePowerUp/purchasePowerUp)、refreshPowerUps、loadPowerUpsFromPlatform、powerUpRefreshInterval、postMessage 监听器、PlatformBridge.consumePowerUp 调用
- **新增**：极简 PlatformBridge (仅 isPlatformMode + init)，init() 中监听 `allinone:item-redeemed` / `allinone-item-redeemed` CustomEvent → 直接 gameStats.powerUps[type]++
- **简化**：handlePowerUpClick — count==0 时仅提示"请使用兑换码"；restartGame 移除 loadPowerUpsFromPlatform 调用
- **新流程**：兑换码输入 → SDK postMessage REDEEM_ITEM → 平台验证 → SDK 分发 allinone:item-redeemed CustomEvent → 游戏监听器直接 powerUps++ → 道具可用
- **验证**：0 残留引用（refreshPowerUps/loadPowerUpsFromPlatform/consumePowerUp/purchasePowerUp/getPowerUpCounts/callSkill 全消失）

## Match3Game 道具修复（Round 2）— CustomEvent 监听器守卫修复
- **新根因**：PlatformBridge IIFE 在定义时检查 `isPlatform`（闭包变量），但 `__ALLINONE_CONFIG__` 可能尚未注入 → `isPlatform=false` → `init()` 中 listenr 被 `return` 跳过 → 永远不监听 `allinone:item-redeemed`
- **修复**：
  1. CustomEvent 监听器始终注册（移出 isPlatform 守卫），反正独立模式下无害
  2. `isPlatform` 检测从 IIFE 闭包移至 `init()` 内部（延迟到调用时）
  3. 新增 `ITEM_MAP` 兼容多种 itemId 格式（match3_bomb / bomb）
  4. 新增 console.log 日志用于调试（`[Match3Game] CustomEvent 收到: xxx → powerUps.xxx=N`）

## Match3Game 道具修复（Round 3）— 重复计数修复
- **根因**：SDK 同时分发 `allinone:item-redeemed` 和 `allinone-item-redeemed` 两个事件。旧代码监听 dash 版后重新分发为 colon 版 → 循环触发 → 1 个兑换码 +2
- **修复**：只监听 `allinone:item-redeemed` 一个事件名，不转发

## VoucherCard 崩溃修复
- **错误**：`TypeError: Cannot read properties of undefined (reading 'icon')` at VoucherCard.tsx:76
- **根因**：`VoucherStatus` 有 5 个值（ACTIVE/FROZEN/EXPIRED/DESTROYED/REDEEMED），`statusConfig` 只覆盖了前 3（后有人补了 DESTROYED），缺 REDEEMED → `statusConfig[voucher.status]` 返回 `undefined`
- **修复**：
  1. 添加 `REDEEMED` 状态配置（紫色/CheckCircle2/"已兑换"）
  2. 添加 `DEFAULT_STATUS` 兜底（灰色/AlertCircle/"未知"），`statusConfig[...] || DEFAULT_STATUS`
  3. 0 lint 错误
