# 2026-06-08 工作日志

## 道具工坊 SOP 改造（P0+P1+P2 全部完成）

### 核心理念变更
从"平台硬编码 3 种通用 Schema（weapon/shop/quest）+ 关键词匹配"转向"游戏方自行注册 SOP + 玩家自由创作"。

### 具体修改

1. **SchemaRegistry.ts** — 新增 `match3-powerup` 游戏专用 Schema
   - 8 种效果 API: remove_area/remove_row/remove_col/remove_color/add_time/add_moves/replace_color/shuffle
   - 完整的 aiGuide（效果规则、约束条件、禁止事项）
   - 新增 `autoRegisterGameSchemas(gameId)` 方法
   - 新增 `generateSOPMarkdown(schemaName)` 方法生成可复制 SOP 文档
   - 新增 `GAME_SCHEMA_MAP` 静态映射 (match3→match3-powerup)
   - 保留 weapon/shop/quest 通用 Schema 兼容

2. **ProtocolAIBridge.ts** — 移除 `guessSchemaFromIntent()` 关键词匹配
   - 改为：游戏声明 Schema→自动选择；未声明→列出所有 Schema 供玩家选择
   - 模板回退路径新增 match3-powerup 的效果关键词映射

3. **ugcBridgeService.ts** — 新增 `createFromJSON()` 粘贴模式 + SOP 文档
   - `createFromJSON()`: 解析 JSON→自动匹配 Schema→校验→创建模板
   - `generateSOPMarkdown()`: 生成游戏 SOP Markdown 文档
   - `buildTemplateFromData()`: AI 和粘贴模式共用
   - `estimatePrice()`/`inferRarity()`: 新增 match3-powerup 定价和稀有度逻辑
   - `getAvailableSchemas()`: 自动调用 autoRegisterGameSchemas

4. **AIDialog.tsx** — 双模式创作入口
   - AI 对话模式（原有，更新了快捷提示为 Match3 语境）
   - 粘贴 JSON 模式（新增，含 JSON 编辑器、校验、示例填充）
   - SOP 文档折叠区域（可复制给外部 AI）
   - Ctrl+Enter 快捷提交

5. **ItemWorkshop.tsx** — 步骤标签更新 + 能力展示适配
   - "AI 创造"→"创造道具"
   - 能力展示适配 match3-powerup（显示可用效果数量、加时上限、颜色等）
   - 底部提示更新

6. **Match3Game.html** — 通用效果执行器
   - 新增 `EFFECT_HANDLERS` 对象，8 种效果（含 3 种内置向后兼容）
   - `usePowerUp()` 重构为通用效果分发器
   - 新增 `useCustomPowerUp()` 处理 UGC 道具
   - 新增 `customPowerUps` 数组 + `renderCustomPowerUps()` 动态 UI
   - PlatformBridge 更新：支持通用 effect 字段 → 自动添加到自定义道具
   - 本地模式预置示例自定义道具（冷冻时间、万能方块）
   - 即时效果（add_time/add_moves/replace_color/shuffle）直接应用
   - 消除效果（remove_area/remove_row/remove_col/remove_color）需点击棋盘格
