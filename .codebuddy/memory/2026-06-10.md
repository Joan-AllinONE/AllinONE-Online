# 2026-06-10 工作日志

## UGC 道具无法使用 — 根因修复

### 问题
UGC 道具（如通过 AI 对话创建的 match3-powerup Schema 道具）兑换后无法在游戏中生效。控制台显示"未知道具ID: match3-powerup 跳过"和"自定义道具, 无自动执行脚本: match3-powerup"。

### 根因
1. **`voucherItemService.ts` 创建兑换码时丢失 Schema 字段**：`gameEffect` 被精简为只有 `itemId/quantity/metadata`，`schemaName` 和 `itemData` 被丢弃。导致 GamePlay.tsx 的 `gameEffect.schemaName && gameEffect.itemData` 条件永远为 false，`EXTENSION_VOUCHER` 从不发送。
2. **`Match3Game.html` 的 `onItemRedeemed` 不识别 UGC 道具**：`ITEM_MAP` 只认 `match3_bomb/lightning/rainbow`，不认来自 `EXTENSION_VOUCHER` CustomEvent 的 UGC 道具（`source: 'ugc'` + `voucherData.effect`）。

### 修复
1. **`src/types/redeemCode.ts`**：`HostedItem.gameEffect` 增加 `schemaName?: string` 和 `itemData?: Record<string, any>` 字段
2. **`src/services/voucherItemService.ts`**（两处）：创建兑换码时保留 `schemaName` 和 `itemData` 到 `gameEffect`
3. **`AllinONE Online/Match3Game.html`**：`onItemRedeemed` 新增 UGC 道具处理分支——当 `itemId` 不在 `ITEM_MAP` 中，检查 `detail.source === 'ugc'` 和 `detail.voucherData.effect` 是否匹配 `EFFECT_HANDLERS`，匹配则添加到 `customPowerUps`

### 道具交付路径（修复后）
- 内置道具：`REDEEM_RESULT` → Inject SDK CustomEvent → `onItemRedeemed` → `ITEM_MAP` 映射 → `powerUps++`
- UGC 道具：`REDEEM_RESULT`（Effect Engine 打 custom 日志 + 未知 itemId 跳过）+ `EXTENSION_VOUCHER` → Inject SDK CustomEvent（`source: 'ugc'`, `voucherData`）→ `onItemRedeemed` UGC 分支 → `EFFECT_HANDLERS` → `customPowerUps`
- `onUGCExtensionVoucher` 兜底：直接监听 postMessage 的 `EXTENSION_VOUCHER`，作为 SDK 未处理时的安全网

### 注意
- 旧兑换码（修复前创建的）不含 `schemaName/itemData`，需重新生成
- build 通过 ✓

## UGC 道具仍无法使用 — 第二轮修复

### 新日志分析
EXTENSION_VOUCHER 已成功发送（上轮修复1生效），但出现两个新问题：
1. `onUGCExtensionVoucher` 日志："UGC 道具无法映射, schemaName: match3-powerup data: {effect: 'remove_area', ...}"
2. SDK CustomEvent 分发 `itemId: match3-powerup` 而非 `remove_area`

### 根因
**`EFFECT_HANDLERS` 作用域问题**：`onUGCExtensionVoucher`（行617）在 `PlatformBridge` IIFE 内部，而 `EFFECT_HANDLERS`（行1232）在 IIFE 外部用 `const` 定义。IIFE 内部闭包引用 `EFFECT_HANDLERS[data.effect]` 时返回 falsy，导致：
- `onUGCExtensionVoucher`：`data.effect && EFFECT_HANDLERS[data.effect]` → false → "无法映射"
- `onItemRedeemed`：同样检查 `EFFECT_HANDLERS[data.effect]` → false → 跳过 UGC 分支

### 修复
1. **`onUGCExtensionVoucher`**：`data.effect && EFFECT_HANDLERS[data.effect]` → 仅 `data.effect`（不检查 EFFECT_HANDLERS，使用时再校验）
2. **`onItemRedeemed`**：同上修改，且增加去重逻辑（`gameStats.customPowerUps.some(...)`），防止 `onUGCExtensionVoucher` 和 CustomEvent 双路径导致道具重复
3. `useCustomPowerUp`（行1441）在 IIFE 外部，可正常访问 `EFFECT_HANDLERS`，无需修改

### 道具交付路径（修复后）
- `EXTENSION_VOUCHER` postMessage → `onUGCExtensionVoucher`（第一优先）→ `data.effect` 存入 `customPowerUps` ✓
- SDK CustomEvent → `onItemRedeemed` UGC 分支 → 去重检查 → 跳过（已通过 postMessage 处理）✓
- 用户点击道具 → `useCustomPowerUp` → `EFFECT_HANDLERS[item.effect]` → 执行效果 ✓

- build 通过 ✓
