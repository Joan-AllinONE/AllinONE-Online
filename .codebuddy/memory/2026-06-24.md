### 设计原则

- **命令注入模式**：effectCode 通过 `game.emit(cmd)` 注入命令，走游戏引擎自身管线（emit → localCommands → takeLocal → stepWith → applyCommands）
- 与 Match3Game 的"直接状态修改模式"形成对照
- 不破坏锁步模拟的 hash 一致性（命令在 applyCommands 中统一处理）
