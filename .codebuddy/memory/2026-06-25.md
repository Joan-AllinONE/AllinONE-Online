## RA2 模板道具分发 BUG 修复

### 问题
- effectCode 形式道具（如战地资金包）可以生效 ✅
- 道具模板创建的道具（只填游戏内ID如 add_cash、reveal_map）无效 ❌
- 控制台显示"没有可执行的代码"

### 根因分析（双层 BUG）
1. **PublishingPipeline.ts BUG**：`ra2-item` schema 落入 `else` 分支，只检查 `v.data.effectType`，不检查 `v.data.effect` → 导致 `itemId` 变成 "ra2-item" 而非 "add_cash"
2. **RA2 桥接 JS BUG**：`handleRedeemedItem` 不检查 `detail.voucherData` → CustomEvent 路径丢失 effect/effectCode/effectScript

### 修复内容
1. **PublishingPipeline.ts**（两处，第962-976行和第2010-2028行）：
   - `else` 分支改为 `(v.data && v.data.effect) || (v.data && v.data.effectType) || v.schemaName`
   - 所有自定义 schema 现在优先提取 `effect` 字段
2. **ra2-allinone-bridge.js**：
   - `handleRedeemedItem`：增加 `detail.voucherData` 提取，过滤 `effectType='custom'`
   - `useCustomPowerUp`：增加三级执行优先级 `effectScript > effectCode > effect（内置效果表）`
   - message handler：增加 `effectType` 回退提取，排除 `'custom'`
3. **红警复刻版v2.html** 重新构建（9MB）
4. 主项目 `pnpm build` ✅ 通过

## 道具重复分发 BUG 修复（"买1个道具得到2个"）

### 问题
- 用户购买一个道具、获得一个兑换码、但兑换后得到2个道具

### 根因分析（双重分发）
1. **GamePlay.tsx onRedeem 回调**：兑换成功后同时做了两件事：
   - 返回 `REDEEM_RESULT` → ProtocolEngine 发回游戏 iframe → SDK 分发 2 种格式 CustomEvent
   - 又显式发送 `EXTENSION_VOUCHER` → 游戏 iframe → 桥接 message handler 处理
   - 结果：同一条道具通过 2-3 个通道到达游戏
2. **SDK 双格式 CustomEvent**：同时分发 `allinone-item-redeemed`（旧）和 `allinone:item-redeemed`（新）
3. **游戏端双监听**：RA2 桥接和超级玛丽都监听两种格式 → 同一道具被 2 次 `handleRedeemedItem`

### 修复内容（统一为单一通道 + 单一事件格式）
1. **GamePlay.tsx onRedeem**：
   - 移除单独发送 `EXTENSION_VOUCHER` 的代码块
   - 改为在 `REDEEM_RESULT` 中增加 `voucherData`（完整 itemData）和 `schemaName`
   - 道具数据通过 REDEEM_RESULT → SDK CustomEvent 单一通道传递
   - URL 参数路径（voucherItemService）仍使用 EXTENSION_VOUCHER（独立通道）
2. **ProtocolChannel.ts RedeemResultData**：增加 `voucherData` 和 `schemaName` 类型字段
3. **PublishingPipeline.ts SDK**：
   - REDEEM_RESULT 处理器：只分发 `allinone:item-redeemed` 一种格式，detail 增加 `voucherData`/`schemaName`
   - EXTENSION_VOUCHER 处理器：只分发 `allinone:item-redeemed` 一种格式
   - `AllinONE.onItemRedeemed` API：监听新格式
4. **standard-sdk/index.ts**：只分发一种格式 CustomEvent
5. **GameStore.tsx**：监听新格式
6. **RA2 桥接**：只监听 `allinone:item-redeemed` 一种格式
7. **超级玛丽**：只监听一种格式，移除 `_redeemedEventIds` 去重逻辑
8. **文档/UI 更新**：所有 `allinone-item-redeemed` 引用改为 `allinone:item-redeemed`（标注旧格式已废弃）
9. 主项目 `pnpm build` ✅ 通过
