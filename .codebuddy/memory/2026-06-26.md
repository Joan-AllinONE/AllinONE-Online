## effectCode "禁止关键词: window" 校验 BUG 修复

### 问题
- 道具工坊高级模式下，effectCode 包含 `window.__ra2allinone` → JSON 校验失败："effectCode 包含禁止关键词: window."

### 根因
- `SchemaRegistry.ts` 第 409-421 行 `blockedPatterns` 一刀切禁止了 `'window.'`
- RA2 桥接沙箱通过参数注入 `game`（即 `window.__ra2allinone`），effectCode 应使用 `game` 而非 `window.__ra2allinone`

### 修复内容
1. **SchemaRegistry.ts**：`blockedPatterns` 从硬编码改为智能校验
   - 从 Schema 的 `aiGuide.creationTiers.advanced.effectCodeSandbox` 配置中提取安全桥接对象白名单
   - `window.__ra2allinone` 等白名单桥接对象允许访问，其他 `window.` 访问仍禁止
   - `blockedPatterns` 不再包含 `'window.'`，改为正则提取 `window.xxx` 并逐个检查
2. **ugcBridgeService.ts**：`registerGameSop` 的两处 `advanced` 配置增加 `effectCodeSandbox: sop.effectCodeSandbox || {}`
3. **SOP 和 JSON 示例**：effectCode 从 `window.__ra2allinone` 改为 `game`（沙箱注入参数）
   - 红警 SOP.md：指挥部礼包 + 指挥官特权示例
   - 红警SOP JSON.json：三角雷区示例（改用 game.emit）
   - 红警集成/红警SOP JSON.json：同步更新
4. 主项目 `pnpm build` ✅ 通过，0 lint 错误

## effectCode "Function(" 正则误判 BUG 修复

### 问题
- 红警复刻版v2.html 报错：`[AllinONE] effectCode 安全校验失败: command_pack`
- command_pack 的 effectCode 包含 `function(params)` 函数定义

### 根因
- RA2 桥接 JS（`红警复刻版v2.html` 第 1911 行 + `ra2-allinone-bridge.js` 第 384 行）的安校正则 `/Function\(/i` 的大小写不敏感匹配
- `function(params)` 小写的 `function(` 被误判为危险的 `new Function` 构造器调用

### 修复
1. **红警复刻版v2.html**：正则从 `Function\(` 改为 `new\s+Function\(`，精确匹配危险的构造器调用
2. **ra2-allinone-bridge.js**：同样修复正则
3. SchemaRegistry.ts 的字符串匹配 `'new Function'` 不受影响（需要同时有 `new` + `Function`）
