# 2026-07-12

## 移动端游戏显示不适配调试（GamePlay.tsx）
- **现象**：用户在手机上测试，所有游戏画面都显示不适配。
- **根因**：所有游戏共用的平台外壳 `src/pages/GamePlay.tsx` 的游戏区用 `aspect-video`（16:9 固定比例）。手机竖屏（宽约375px）下游戏区高度被压到约211px，每个游戏都被挤成一条；顶部栏按钮在窄屏下拥挤。
- **已修复**（仅改 GamePlay.tsx，影响全部游戏）：
  1. 游戏区容器：`aspect-video` → 移动端 `h-[68dvh] lg:h-auto lg:aspect-video`（手机占视口高度，桌面恢复16:9）。
  2. Header：窄屏缩小内边距/字号、标题 `truncate` 防溢出、商店文字 `hidden sm:inline`、按钮缩小且 `shrink-0` 防收缩。
  3. 根容器加 `overflow-x-hidden` 防横向滚动。
  4. 奖励 Toast：移动端缩小内边距 + `max-w-[92vw]` + 标题 `text-sm sm:text-lg`。
- **lint**：0 错误。
- **待确认**：游戏 HTML 内部（如 Match3Game 固定 `--gem-size:48px`、`.game-layout` 无 @media）若仍偏小，属游戏自身响应式问题，可后续逐个优化；外壳已给足显示空间。
