# 2026-07-17

## 修复：`pnpm run dev` 报错 'concurrently' 不是内部或外部命令

**症状**：`pnpm run dev`（concurrently 并行启动 dev:server + dev:client）报错 `concurrently 不是内部或外部命令`。

**根因**：`node_modules` 依赖树处于半损坏状态（之前 `pnpm install` 曾超时中断，导致部分包软链接断裂）。`concurrently` 本身缺失，且它依赖的 `rxjs` 模块链接也断（`Cannot find module .../concurrently@8.2.2/node_modules/rxjs/dist/cjs/index.js`）。

**修复过程**：
1. `pnpm add -D concurrently` → 仅补了 concurrently 自身，但 rxjs 链接仍断
2. `pnpm install --prefer-offline` → 报 "Already up to date"（pnpm 元数据认为已装好，不会重链）
3. `pnpm install --force` → 强制重链全部 651 包（2m37s），rxjs 链接恢复，concurrently 8.2.2 正常

**关键经验**：当 pnpm 报 "Already up to date" 但某模块 Missing 时，说明 node_modules 软链接已断裂，**必须用 `pnpm install --force` 强制重链**，普通 install/add 不会修复。

**验证**：`node_modules/.bin/concurrently --version` → 8.2.2 ✓；`node_modules/.bin/vite --version` → 6.3.5 ✓。

## 修复：`pnpm run dev` 报 ERR_MODULE_NOT_FOUND dist/server/server/memoryDatabase.js

**症状**：concurrently 修好后，`dev:server`（node server.js）报错 `Cannot find module '.../dist/server/server/memoryDatabase.js'`。

**根因**：`server.js` 导入的是 `tsc` 编译产物（`dist/server/server/*.js`，由 `tsconfig.server.json` 的 outDir=./dist/server + rootDir=./src 生成）。`dev` 脚本只并行起 server+client，**没有先构建 server**，故 dist 缺失。

**修复**：
1. `tsconfig.server.json` 加 `noEmitOnError: false`（避免类型警告阻断输出，匹配之前能成功构建的配置）
2. `package.json` 的 `dev` 脚本改为 `pnpm run build:server && concurrently ...`，先构建 server 再并行启动
3. 手动 `pnpm run build:server` 验证 → 成功生成 `dist/server/server/memoryDatabase.js` 及 `routes/games.js` ✓

**关键经验**：`server.js` 依赖 `dist/server` 编译产物，跑前必须先 `build:server`；dev 脚本已内置此步骤。
