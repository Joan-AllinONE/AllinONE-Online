- `publishedGameService.ts:729 游戏已保存到 CloudBase + 缓存: lf2-flat5`，且 `游戏文件已缓存到 IndexedDB: game-1784369428401, 346 个文件`。

**本次加固（用户无需重发/无需后端在线即可加载）**：
1. `public/gameFileServiceWorker.js` 升级：在「后端优先 + Cache Storage 回放」之后，新增**第三级回退——从 IndexedDB 本地文件缓存（AllinONE_GameFiles/game_files/key=gameId）回放**，带正确 MIME + 宽松 CSP（与后端 `/files/` 一致）。精确键 miss 时**扫描全部游戏键**兜底（解决发布 gameId 与存储键不一致）。
2. `src/pages/GamePlay.tsx`：模块化游戏（isModular）**强制构造真实 URL** `/api/v1/games/:id/files/:entryPoint` 并设 hostingType='server'，交给 SW 从 IndexedDB/后端取文件，永不到 srcDoc 内联。
3. 已 `pnpm run build:client`，dist/static/gameFileServiceWorker.js 含新逻辑。

**给用户的可操作步骤**：仅需在浏览器硬刷新（Ctrl+Shift+R）GamePlay 页即可；SW 重新激活后从 IndexedDB 提供 346 个文件，RequireJS 子资源同域加载成功。若走生产托管需 `build:client` 后由 server.js 同源提供。注意 dev 后端若仍跑旧构建，SW 网络优先会拿到 404，但会自动回退 IndexedDB，不影响。

## 平台入口识别/游戏加载白屏修复（A+B+C 方案）实施完成

用户反馈游戏入口识别与加载问题（附 `AllinONE Online/lf2-flat5` 与 `平台入口识别问题说明.md`）。

- **B 健壮性**：新增 `public/gameFileServiceWorker.js`，拦截 `GET /api/v1/games/:gameId/files/*`，后端优先、失败回放 Cache Storage（保持 MIME）；`src/main.tsx` 注册（站点根，仅过滤游戏文件请求，不影响其他）。经 `vite build --outDir dist/static` 已拷至 `dist/static/gameFileServiceWorker.js`。
- **C 检测+显式报错**：`GameCodeAnalyzer.analyzeFileStructure` 新增 `isModular`（检测 requirejs/define/import(/data-main/已知加载器）；`types/index.ts` 的 `FileStructureInfo` 加 `isModular`；`PublishedGame` 加 `isModular?`；`PublishingPipeline.stepRegisterPlatform` 写入；`GamePlay` 模块化游戏误用内联时显式报错提示改用服务端托管模式重发。
