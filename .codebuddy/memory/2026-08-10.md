# 2026-08-10

## 手机端新发布游戏加载失败（NoSuchKey）修复

**症状**：电脑跨浏览器能玩，手机/iOS 隐私模式首次访问报
`404 Not Found / NoSuchKey / Key: api%2Fv1%2Fgames%2Fgame-xxx%2Ffiles%2Findex.html`。
最早发布的游戏能玩，新发布的 2 个不行。

**根因**：SW 未激活时，`GamePlay.tsx` 构造的同源相对 `/api/v1/games/...` URL 被 CloudBase 静态托管
rewrite 当 COS 对象读取 → NoSuchKey。电脑能玩是因为 SW 早激活、把请求代理到云函数绝对 URL。

**双管齐下修复（已实施）**：
1. `cloudbase.json`：`rewrites` 新增 `{source:"/api/**", functionName:"gamesApi"}` 置于 `**→/index.html` 之前。
   治本：SW 失效时 `/api/**` 直接路由到云函数。
2. `src/pages/GamePlay.tsx`：新增 `buildGameFileUrl(gameId, entryPoint)`，
   tcloudbaseapp.com 下返回绝对云函数 URL，dev 返回相对路径。server 模式 iframe cdnUrl 改用它。
   加固：不依赖 SW 代理跨域请求（SW 本就无法拦截跨域）。

**验证要点**：云函数 `GET /:id/files/*` 已就绪（从 game_files 集合匿名直读），
CORS `Access-Control-Allow-Origin: *` 已设置 → 跨域 iframe 可加载。
**部署后需重新 hosting deploy（前端）+ 确认 cloudbase.json rewrites 生效**（无需重新部署云函数）。
