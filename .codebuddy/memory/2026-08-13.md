## 2026-08-13 下午：隧道化接通后的代码自检 + bug 修复（已部署验证）

本次改动较大，自检发现并修复 4 个确定 bug（均 `tcb fn deploy gamesApi` 重新部署验证通过）：

1. **【严重】玩家串号（userId 全 anonymous）**：云函数各 handler 用 `getUserIdFromPayload(body)` 取 userId，
   但前端游戏内服务请求只带 `Authorization: Bearer <dev-token>`，body 里无 userId → 所有玩家数据落到
   `anonymous::gameId` 串号。修复：新增 `getUserIdFromAuth(authorization)`（从 JWT payload 解 userId），
   `resolveUserId` 优先 token→回退 body；分发处把 `authorization` 传入各 handler。已验证 player123/player456 隔离、无 token 落 anonymous。

2. **【严重】钱包模型不匹配（reward/spend/exchange 全 400）**：前端 WalletAPI 用多币种对象
   `{computingPower, gameCoins, diamonds}`，云函数原 wallet handler 用单一 `balance` 数字 + `body.amount`，
   reward 请求无 amount 字段 → 400。修复：wallet handler 改为多币种对象，reward 累加各币种、spend 按
   `currency`+`amount` 扣、exchange 按 fromCurrency/toCurrency/rate 兑换；balance GET 返回对象。已验证。

3. **【中】game-developers 路径 405**：前端 `recordTransaction` 调 `/transaction`（单数），云函数只匹配
   `/transactions`（复数）。修复：gameDeveloperService.ts 改为复数 `/transactions`。已验证。

4. **【中】GET 钱包请求 missing gameId**：CloudBase HTTP 访问服务把 query 放 `event.queryStringParameters`
   /`event.queryString`，不在 `event.path`，`parseQuery(path)` 取不到。修复：分发处合并 `event.queryString`
   进 `q`；前端 WalletAPI.refreshBalance/getTransactions 补 `?gameId=`。

**遗留待确认（非阻塞，展示降级）**：LeaderboardAPI/AchievementAPI 部分 GET 返回的 data 结构（name/totalEntries 等）
云函数未填充，前端有展示降级但不报错。
