## 修复：QuestDetailModal 领取任务后白屏（同日，用户报 bug）

### 根因
P2 时在 `QuestDetailModal.tsx` 第 283 行 label 加了 `资源文件 assets（可选，JSON 数组 [{path, content}]）`，
JSX 把 `{path, content}` 当成表达式解析（path 未定义）→ `Uncaught ReferenceError: path is not defined` → React 渲染崩溃白屏。
> 引号内 `[{path, content}]` 里的大括号不是 JSX 文本，是被求值的表达式！

### 修复
label 文本改为字符串表达式 `{'资源文件 assets（可选，JSON 数组 [{ path, content }]）'}`。
并 grep 检查 quest 目录下所有 JSX 文本，无其他同类问题。

### 教训
JSX 文本中若需展示字面花括号（如 JSON 示例 `[{a, b}]`），必须包成 `{'...'}` 字符串表达式，
不能直接写裸 `{a, b}`（会被当表达式解析 → ReferenceError 白屏）。
