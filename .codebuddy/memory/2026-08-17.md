## 方案 E「注入型扩展」（加载时注入 HTML，同日实施完成）

需求根因：超级玛丽改造6 无 A1G_EXT 加载器，任务喂的数据/脚本它吞不下；用户要求「任务系统可直接注入 HTML」的第二条路径。

### 架构（模式 2：注入型，层次 A 加载时注入）
- **数据模型**：`ContentPack.inject?: boolean`；`QuestInjectionRecord`（submissionId/name/slot/code/mergedAt）→ 存 `published_games[gameId].injections[]`；`QuestExtensionRecord` 加 `inject?/name?`（游戏页「扩展菜单」展示注入扩展）
- **merge 层**：`inject:true` 时 `extractInjectScript(pack)`（优先 data.code，否则第一个 .js 资产）写入 injections（按 submissionId 去重），**data 绝不追加到 slot 数组**（`dataIsEmpty = inject===true`）；同时 questExtensions 记录 `inject:true`。本地 `src/server/routes/quests.ts` + 云函数 `cloudfunctions/gamesApi/index.js` 双实现
- **加载层**：`public/gameFileServiceWorker-v12.js` 新增 `fetchGameInjections`（GET 游戏详情）+ `applyInjectionsToHtml`（`</body>` 前拼 `<script>`，转义 `</script`）+ `isEntryFile`（entryPoint 兜底 index.html）；入口 HTML 后端命中时注入，结果入 Cache/IndexedDB（离线兜底也有注入）。**SW bump v11→v12 + main.tsx 注册路径同步**；`CACHE_NAME` 升 v2 使旧缓存失效
- **GamePlay.tsx**：inline/srcDoc 模式 `useMemo` 对 `game.injections` 做同样注入（`gameHtmlInjected`）；`computeEffectiveGame` 对 `questExt.inject` **不改变加载方式**（server 走 SW 注入、inline 走前端注入，不透传 ?ext=）
- **校验**：注入模式跳过 slot 结构校验 + 危险代码扫描（代码即交付物，安全靠审核）；`validateQuestContent`/云 `validateQuestSlot` 仅要求有 .js 资产或 data.code；`QUEST_SLOT_SCHEMAS` 新增 `inject` slot
- **UI**：`QuestDetailModal` 提交表单加「注入模式」复选框；`QuestPublishGuide` 加「模式 E：注入脚本/MOD」+ 速查/FAQ/清单更新

### 用户使用路径（超级玛丽第三关 MOD）

## 注入资产升级：CSS / 图片 / 声音（同日，用户追问「js 注入解决了，css/图片/声音怎么解决」后实施）

### 核心思路（复用已有落库资产，不重复存储）
merge ①b 早已把 assets 全部写进游戏文件库（路径 `extensions/{questId}/{submissionId}/{path}`，GET /files/* 公开分发）。之前注入链路只搬运「一段 JS」，缺「给注入代码的资产寻址 + CSS 自动生效」→ 本轮补齐。

### 数据模型
- `QuestInjectionRecord` 增 `styles?: string[]`（data.css 内联样式）/ `assets?: Array<{path,size,mimeType}>`（全部资产清单）/ `assetBase?: string`（`extensions/{questId}/{submissionId}/`）
- `publishedGameService.ts` 的 `injections` 类型同步加同名字段
- inject slot `allowedAssetExts` 放宽到 `['js','mjs','css','json','png','jpg','jpeg','gif','webp','svg','mp3','wav','ogg','mp4','webm','woff','woff2','ttf','otf']`

### merge 层
- `extractInjectScript` → `extractInjectPayload(pack, nsEntry)`：返回 `{ code, styles }`（code 取 data.code 或首个 .js 资产，styles 取全部 .css 资产内容，均跳过 `__BINARY_BASE64__`）
- ①d 写入时增 `styles/assets/assetBase`（assetBase = `nsEntry`，即 ①b 已有的命名空间）
- 本地 `quests.ts` + 云函数 `gamesApi/index.js` 双实现

### 注入器升级（四处一致：dev `games.ts` / 云函数 / SW v13 / GamePlay.tsx）
新函数 `buildInjectionBlock(inj, resolveBase)` + `rewriteCssUrls(css, base)` + `escapeHtml`，注入块结构：
1. **CSS 文件资产 → `<link rel="stylesheet" href="{base}{basename}">`**（CSS 内 `url(img.png)` 相对 CSS 自身解析，天然正确）
2. **data.css 内联 → `<style data-allinone-css>` + `rewriteCssUrls`**（把 `url(相对)` 重写到 assetBase 前缀）
3. **资源帮助器**：`window.AllinONE_INJECT[sid]={base, url(p)=>base+p}` + `window.AllinONE_asset=(p)=>...url(p)` → 图片/声音/字体寻址
4. 用户脚本（原逻辑）+ label 内 `--`→`-` 防 HTML 注释闭合
- **resolveBase 两态**：server/SW/云函数默认相对 `inj.assetBase`（浏览器按文档 base 解析）；GamePlay inline/srcDoc 必须传绝对 `buildGameFileUrl(game.id, inj.assetBase)`（**srcDoc baseURI=about:srcdoc，相对寻址必挂**）
- `applyInjectionsToHtml` 签名加可选 `resolveBase`，幂等标记不变

### SW bump v12→v13
- 新文件 `public/gameFileServiceWorker-v13.js`（注入器升级 + `CACHE_NAME v2→v3`），删除 v12，main.tsx 注册路径同步
- QuestDetailModal 注入复选框提示 + QuestPublishGuide 模式 E 补「CSS/图片/声音用法示例」（`AllinONE_asset('bg.png')` / `new Audio(AllinONE_asset('bgm.mp3'))`）+ 踩坑 v12→v13

## 自检发现并修复 2 个 bug（同日第二轮）
1. **CSS 子目录 href 错误（确定 bug）**：注入器 CSS link 原用 `base + basename`（`split('/').pop()`），CSS 资产带子目录（如 `css/style.css`）时 href=`assetBase/style.css` ≠ 实际存储 `extensions/q/s/css/style.css` → 404。**修复（四处注入器 games.ts/云函数/SW v13/GamePlay.tsx）**：`full = a.path`，`rel = full.startsWith(inj.assetBase) ? full.slice(assetBase.length) : full`，href = `base + rel` → 相对模式=完整扩展路径、inline 模式=绝对 URL，两态都正确。
2. **默认 resolveBase `'extensions/'` 前缀错误**：无 assetBase 的旧数据会被拼上 `extensions/` 前缀 → 错误。**修复：默认改为 `inj.assetBase || ''`**。
3. **验证通过**：CORS（云函数文件响应 `Access-Control-Allow-Origin: *`，跨域 iframe 加载 CSS/图片/媒体无阻）；CSP（本地 games.ts `style-src/img-src/media-src/font-src 'self'` 对同源注入放行）；文件分发对 `extensions/` 精确匹配（云函数 game_files.find + 本地 memoryDB.getGameFile）；memoryDB `mime_type` 字段名与 games.ts 注入条件一致；云函数/本地 ①d 段 `assetManifest`/`nsEntry` 作用域正确；详情 GET /:id 返回完整文档含 injections（SW fetchGameInjections 依赖）。手工断言脚本验证：子目录/根目录 CSS link、`url()` 重写、inline 绝对 base、帮助器注入全部 PASS。重新 build ✓ 1m38s，SW v13 进 dist。
