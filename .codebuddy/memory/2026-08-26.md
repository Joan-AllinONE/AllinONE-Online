## 游戏简介功能（发布游戏时填文字+传封面）
- 需求：发布游戏时开发商可填写游戏简介文字 + 上传游戏封面。
- 实现：
  - `PublishedGame` 接口新增 `summary: string` 与 `coverImage: string`（封面存 base64 data URL，前端上传时 canvas 压缩到最大宽 800px / JPEG 0.85，直接存文档，与 entryHtmlContent/SOP 同机制，经列表 API 跨浏览器匿名可读）。
  - `PublishingPipeline.publish()` 组装记录时带入 `summary`/`coverImage`（从 publishConfig 取）。
  - `PublishingCenter.tsx` 新增「游戏简介」配置标签页（FileText 图标 tab）：封面图上传(含预览/重传/移除) + 简介 textarea(500 字限制)；独立 state `summary`/`coverImage` + `coverInputRef` + `handleCoverChange`(压缩)；注入 publishConfig 并加入发布 effect 依赖。
  - `GameCenter.tsx` 卡片：有封面则顶部显示 40h 封面 banner（hover 放大），描述回退 `summary || description`。
- 验证：`tsc --noEmit` 我改的 4 文件 0 报错（其余 voucher-system 报错为既有、非本次引入）。封面图走文档内联，无需改云函数/列表 API（不在 entryHtmlContent 排除项）。
