## 内容工坊看不到已启用「内容创作」的游戏（修复）

根因：`savePublishedGame()` 末尾 `invalidateGamesCache()` 清空内存缓存，而 dev 下 `getPublishedGames()` **只读内存缓存**（localStorage 被短路）→ `src/pages/PublishingCenter.tsx` 的 `handlePublishComplete` 同步 `getPublishedGame(gameId)` 恒为 null → 走进「跳过二次保存」分支；而 `contentSop` / `contentSopDocument` **只在这步写入** → 内容工坊过滤 `contentSop?.enabled` 永远为空。日志特征：`[PublishingCenter] 未找到管线保存的游戏记录，跳过二次保存`。

修复：
1. `handlePublishComplete`：同步读不到时先 `await refreshGameDetail(gameId)`（GET /:id 公开路由）异步拉一次；仍读不到则改为 `patchGameOnBackend` **局部 PATCH** 只补写 contentSop/contentSopDocument/itemSop/sopDocument，绝不用残缺对象整体 upsert（会清空封面/简介/hostingType）。
2. `ContentWorkshop` 列表：监听 `games-list-updated` 事件重读 + 1200ms 延迟重读兜底（挂载时后台刷新可能未完成 → 空列表）。
3. 补充说明：本地后端跑的是 `dist/server/**`（tsc 产物），改 `src/server/**` 后必须 `node node_modules/typescript/bin/tsc -p tsconfig.server.json` 重新编译，否则 dev 行为不同步（控制台 dev-token 400 即旧产物所致）。
