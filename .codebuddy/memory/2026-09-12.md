## 修复：绑定奖励测试不发奖（2026-09-12，未部署）
- 现象：设置奖池+绑定游戏后测试，无任何 `[PlatformBindingService] 发放` 日志。
- 根因（发奖触发链路两断点）：
  1. **游戏侧从不发事件**（主因）：GamePlay 的 `triggerGameReward` 只由协议 `game:event` 触发（GAME_COMPLETE/GAME_WIN/LEVEL_COMPLETE/ACHIEVEMENT_UNLOCK/SCORE_MILESTONE，ProtocolEngine 处理 `type:'GAME_EVENT'` 的 postMessage）；超级玛丽改造6.html 只有接收 EXTENSION_VOUCHER 的监听、从不 postMessage 上报 → 事件处理器从未执行（日志无「没有配置奖励规则」也无「触发奖励」即为证据）。
  2. **GameCenter 只对外链游戏点击发 GAME_CLICK**：server/inline 托管游戏走 `<Link to=/game/:id>` 直接跳转，无触发。
- 修复：① GameCenter 新增 `handlePlatformGameClick`，isPublished/原生游戏点「游玩」也 fire-and-forget 触发（与外链点击即得一致，绑定 limits 防刷）；② 超级玛丽改造6.html 通关点（`player.x >= DOOR_X → state='cleared'`）加 `postMessage({type:'GAME_EVENT',event:'GAME_COMPLETE',...})`。
- ⚠️ **改游戏 HTML 必须重新发布**（超级玛丽改造6 需重发布才有 GAME_COMPLETE 上报）。
- 协议标准：游戏→平台事件 = `window.parent.postMessage({type:'GAME_EVENT', event:'GAME_COMPLETE', data:{score...}, timestamp}, '*')`（standard-sdk `sendEvent` 同构）。
- 附注（非阻断）：dev 大量 404（/api/v1/games/vouchers、users、voucher_transactions、user_pools/batch 等）= 本地 server.js 未实现云函数 collection 隧道路由（线上云函数有），localStorage 兜底不受影响；SOP 503 同理。`distributeSimpleReward` 不筛 triggerMode（触发模式仅元数据），真正决定发放的是触发入口。

## 触发方式语义修复（2026-09-12，未部署）
- 根因：`TRIGGER_MODE_OPTIONS.ON_CLICK.applicableTypes` 只有 `[EXTERNAL]` → 绑定 PUBLISHED 游戏时 UI 不显示「点击游玩时」选项；且发放入口原本不筛 triggerMode（选什么都发，语义悬空）。
- 修复（4 文件）：
  1. platform.ts：ON_CLICK applicableTypes 加 NATIVE+PUBLISHED；全部选项描述精确化（行为类标注「需游戏集成上报，见发布指南 4.7 代码段 E」）。
  2. GameCenter.tsx：点击入口 `getActiveBindingsForGame(gameId, TriggerMode.ON_CLICK)` 只发点击型绑定；**教训：上一轮定义了 handlePlatformGameClick 却忘了接到 Link onClick（tsc TS6133 抓出），本轮补上**。
  3. GamePlay.tsx：事件入口按事件映射——`ACHIEVEMENT_UNLOCK → ON_ACHIEVEMENT`，其余（COMPLETE/WIN/LEVEL_COMPLETE/SCORE_MILESTONE）→ ON_GAME_COMPLETE。
  4. PlatformIntegrationTab.tsx：①切换游戏时当前 triggerMode 不适用则自动回落到第一个可用项；②绑定卡片对行为类触发 + 非外链游戏显示琥珀色提醒「需游戏集成上报，未集成请改选点击游玩时」。
- 发布指南 4.7 同步：新增「运营者绑定触发方式怎么选」对照表（ON_CLICK=无要求立即可用 / ON_GAME_COMPLETE=需代码段 E / MANUAL=仅管理端），并注明同一游戏可叠加多条绑定独立防刷。
- 语义规则（铁律）：**发放入口 ↔ 触发方式一一对应**——点击入口只发 ON_CLICK 绑定；游戏事件入口按事件映射发对应模式绑定；MANUAL 不参与自动发放。
