## 修复：A币凭证购买道具后钱包交易记录不显示（未部署）
- 现象：用游戏奖励发的 A 币凭证购买道具（voucher 支付），钱包页交易记录无此笔。
- 根因：`voucherItemService.purchaseItemVoucher` 两条支付路径不对称——
  - wallet 支付 → `wallet.spend` → adjustBalance 写 transactions 流水 → 钱包可见 ✓
  - voucher 支付 → 只走 `voucherService.transferVoucher`（写凭证系统自己的账本 allinone_voucher_transactions）→ **从不写 WalletSkill 的 transactions** → 钱包页（wallet.getTransactions）看不到 ✗
- 修复：
  1. `WalletSkill.ts` 新增 `recordTransaction` action：**只写流水不改 gameCoins 余额**（A币凭证与游戏币是两套账本，余额不混记）；本地 `writeLocalTransaction` 立即可见 + `writeQueue.enqueue transactions`（云端，与其他流水同通道）。
  2. `voucherItemService.ts` voucher 支付分支成功后：记录 expense（净支出=voucherPrice「用A币凭证购买道具: X」）+ 找零>0 时记录 income（「凭证支付找零」）；try/catch 包裹，流水失败不影响购买。
- 陷阱记录：`ActionDefinition` 的注册对象带 `params` 字段会在 tsc 严格模式报 TS2353（项目所有 action 均如此，运行时无害，历史遗留模式）；`getStats` 里 `userId` 未使用也是历史遗留（tsc_check 报错需区分新旧）。
- 404 说明：dev 下 `/api/v1/games/vouchers|voucher_transactions|user_pools` 等全部 404 = 本地 server.js 未实现云函数 collection 隧道路由（与昨日结论一致，localStorage 兜底不受影响）。

## 跨游戏兑换三项改进（2026-09-13，未部署）
1. **删除「打开游戏并使用该道具」按钮**：CrossGameExchangeModal 成功区只保留「道具已下发到正在运行的游戏」提示（路径 B/C）；移除 Link/Gamepad2 import。
2. **差价补齐兜底**：`listConversionOptions` 路径 A 重构为 eligible（有效模板）→ affordable（价格≤源估值，推荐）+ **topUpCandidates（价格>源估值，升序前3，带 `topUpAmount`）**；「暂无可用的兑换方式」场景下差价补齐成为唯一可靠路径；recommendedId 优先无差价等值。
3. **交易手续费 10%**：`calcExchangeFee(targetValue) = targetValue × 10%`，所有路径收取；与差价合并为应付总额。
- **支付实现**（executeConversion 改 **async**）：`paymentMethod: 'gamecoin' | 'voucher'` + `paymentVoucherIds`。
  - gamecoin：`wallet.spend`（只扣 gameCoins，精确；余额不足 gateway 转 success:false + error.message）。
  - voucher：玩家 A 币凭证**整张支付不找零**——差价部分转 `game-{targetGameId}` 开发者账户，手续费部分转 `platform_pool`；校验 ACTIVE+持有者+denomination>0，合计≥应付。
  - **退款**：mint 失败（路径A）/ redeemItemVoucher 失败（路径B/C）→ gamecoin 走 `wallet.recharge` 退、凭证逐张转回；核销源凭证异常的既有兜底不退款（目标凭证已产出）。
- **UI**（CrossGameExchangeModal）：支付明细区（手续费/差价/应付合计）+ 双支付方式卡片（游戏币余额 / A币凭证张数）+ A币**升序贪心自动凑整**预览（明细+不找零提示）+ 余额不足红色提示；确认按钮文案「支付 X 并兑换」、disabled 加 `!canPay`。
- 钱包余额读取：`skillGateway.execute('wallet','getBalance')` → `bal.data.gameCoins`（SkillResponse.data 包装）。
