# 2026-09-16

## 修复：跨游戏道具区块被空状态短路（小红看不到「来自其他游戏的道具」）

**根因**：`src/pages/GameStore.tsx` 「我的道具」tab 中，跨游戏凭证区块嵌套在
`myItemVouchers.length===0 && myPurchases.length===0` 空状态三元表达式的 else 分支内。
仅持有他游戏道具的用户（小红：10 张 Match3 凭证、本游戏数据为 0）走空状态分支，
跨游戏区块被结构性短路；小明因本账号有本游戏测试数据走 else 才可见。数据本身无问题。

**修改**（GameStore.tsx，3 处编辑，0 lint 错误）：
1. 空状态条件补 `&& crossGameVouchers.length === 0`（核心修复）
2. 绿色说明卡片包 `{(myItemVouchers.length > 0 || myPurchases.length > 0) && (...)}`
   ——仅有跨游戏凭证时隐藏，避免与下方靛蓝跨游戏卡片重复
3. 时序隐患无需修：288-300 行已有独立兜底 effect（`[currentUser?.id, gameId]` 依赖），
   登录晚于首次加载时会重算 crossGameVouchers

**验证**：vite build 成功（51.43s，产物 index-Cu3arP5z.js）。本地 dev 直接刷新页面生效。

**测试要点**：小红(test-002)打开玛丽(game-1789169626787)商店「我的道具」tab，
应立即看到 10 张 Match3 道具；同游戏内过滤不显示属设计如此。

**工具经验**：execute_command 对长命令 10s 监控超时会中断；
长构建用 `Start-Process -WindowStyle Hidden -RedirectStandardOutput` 后台跑 + 轮询产物。
Get-Content 必须带 `-Encoding UTF8`（CRAFT 拦截）。
