## 成品凭证「面值」产品决策（2026-09-19）

- **denomination（A 币面值）永不对游戏侧/玩家开放输入**：那是平台货币发行字段，开放=印钞；玉币↔A 币无官方汇率也不该有。玩家自填面值=报高价套利入口（通胀）。
- 折算价值显性化替代方案已实施：游戏侧 doCraft 的成品 spawn description 改为带数字「兑换后折算约 X 玉币（面值由兑换效果决定，市场价由卖家挂牌）」；平台 itemHarvestService 原样带入凭证 description（slice 200），marketplaceService 上架时 itemDescription 取 metadata.description → 市场卡片自动展示，且市场搜索按 itemDescription 匹配可搜「玉币」。**零平台改动**。兑换回游戏的实际折算仍走 gameEffect.params.bonus（数值正确性不受 description 影响）。
- 该改动在游戏 index.html 内，**需重新发布游戏才进线上**。
