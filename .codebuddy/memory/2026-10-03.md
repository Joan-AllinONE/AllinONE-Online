# 2026-10-03

## 智能合约模块 · 完整方案定稿并落盘文档

**产出**：`docs/contracts-design.md`（v1.0 综合终版，17 章 + 2 附录，待用户最终确认后进入实施）

**用户确认项**：
1. 收益来源 = 仅平台内可观测（市场佣金 / 内容按次消费 / 商店销售 / 道具销售），游戏内自有经济不纳入
2. 治理范围白名单 = ADJUST_PRICE / GAME_CONFIG / MINT_CURRENCY（排除下架游戏、核心资产变更）
3. **三档逐步开闸 + 每档先影子对照**（GroupBuy 低 → TeamQuest 中 → GSO 收益分成 高）

**两类合约（范围严格收敛）**：
- **M1 `gso`** 游戏主权/收益权认购：游戏方出让 revenueShareBps + governanceShareBps，社区按 % 认购或买断 → softCap 判定 → 达标交割/未达标全额自动退款 → active 自动分账 + 授予时间加权治理权重。含 perUserCap/coolDownMs/lockupMs/buyback/governableTopics。
- **M2 `team-quest`** 组团任务：objectives 完成度 + deadline 自动判定，payoutRule(equal|byContribution|byRank|custom)，breach{underContributionBps, earlyExitBps, leaderFailBps, forfeitTo}。违约判定必须自动、事实源走 ProtocolEngine channelToken。
- **M3 `group-buy`** 拼团：成团享折扣 / 流团全额自动退款（第 1 档开闸）。

**架构（硬性要求：相对独立）**：
- `src/contracts/`（types / engine 纯函数 / runtime / adapters 接口 / templates / client / ui），ESLint 禁止 import services|skills|voucher-system
- `src/contracts-adapters/` 平台侧唯一耦合处（voucher/wallet/treasury/market/pool）
- ★ engine 编译成**单一产物 `contract-engine.js`**，本地 server 与云函数共用（防 TS/JS 双实现漂移）
- 对外 6 动词：deploy / sign / invoke / query / ratify / verify；`__contract` 隧道双实现
- `contract_templates|instances|events` 三集合 READ_ONLY
- 开关：`CONTRACTS_ENABLED` + `CONTRACT_AUTO_EXECUTE{group-buy/team-quest/gso}` 分档

**三条硬保证**：
- 固化 = canonicalize→SHA256→codeHash→HMAC；`__contract/update` 只许改 state+追加 history，触碰 clauses/effects/parties[].stake/timelock 一律 403；`GET /__contract/:id/verify` 公开复算（照抄 integrity.mintedBy='server' 模式）
- 自动执行 = 四路触发器（event/protocol/cron/manual）+ mathjs 沙箱 + 幂等键 `contractId:triggerId:seq` + 先托管后结算原子语义 + 死信队列
- 无单方篡改 = 全员签署才 funded + 平台密钥 2-of-3（运营/治理合约/社区观察员）+ timelock + 争议窗口 + 违约条件表达式自动判定

**实施路线**：B0 契约基座 → B1 模板与隧道 → B2 GSO 认购交割 → B3 收益分成与治理 → B4 组团族 → B5 管理工具 → B6 可选 Merkle 锚定。
