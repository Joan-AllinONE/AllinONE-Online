## 关键设计决策（B0 落定）
- **codeHash = 规则指纹**：sha256(canonical({templateKey, templateVersion, clauses, params}))；parties/资金变动不进 codeHash，走事件哈希链存证（双层：规则不可变 + 事实不可抵赖）。ContractInstance 冻结 clauses 副本，verify 端点用实例内 clauses 重算自证。
- **instance.clauses 存副本**（非运行时查模板注册表）：versioned 升级时旧实例自治。
- **stateData 数值化**：StateUpdate 仅支持 add/set 数值（计数器）；复杂数据（认购者列表）从 history 事件链推导（事件溯源），不存 stateData。
- **表达式动态字段约定**：EffectSpecFree 字符串字段以 `'expr: '` 前缀表示 DSL 表达式，部署时全部 lint，坏表达式进不了链。
- **package.json**：build 前置守卫（`node scripts/check-contracts-isolation.cjs &&`）+ `check:contracts` 脚本。

## 踩坑记录
- evaluate.ts tokenizer 最初漏了 `.` 运算符 → 23 个用例失败（所有成员访问报非法字符）；加入 ONE_CHAR_OPS 后修复。
- vitest 中 import src 外 .cjs：vite 静态解析失败 + createRequire 相对路径失败 → 用 createRequire + `path.resolve(process.cwd(), ...)` 绝对路径。
- ledger 测试手写 canonical JSON 时键序必须按字母序（actorId<at<payload<seq<type）。
- 篡改事件 hash 的断链位置：verifyChain 先检测到该事件自身 hash 重算不匹配（brokenAt=被篡改的 seq），而非后继事件。
- PS 无 tail；vitest 直接跑会被 10s 监视超时吞输出 → Start-Process 重定向日志 + 轮询（与构建同法）。

## 关键机制（实施中落定）
- **开闸开关 env 化**：`CONTRACT_AUTO_EXECUTE=group-buy[,team-quest,gso]`（CSV）覆盖 config.ts 默认 false；冒烟/本地开闸测试用
- **同触发内条款间状态可见性约定**：join 类条款 when 用 `state.X + 1 >=` 模拟本次加入后（updates 在全部条款评估后才应用）
- **GroupBuy 生命周期**：signing → settling（满员即交割 reach-max 或到期达标 settle-signing）/ refunded（流团）；无 active 中间态；settle-signing 防止"达标未满员"卡死
- **状态机扩展**：signing/funded 可直达 settling/refunded（validate.ts STATE_TRANSITIONS，B0 漏设计已补）
- **DSL 扩展**：`GAME_EVENT:*` 前缀通配（triggerMatches）；SplitTableSpec byField `mode:'share'`+poolAmount（尾差给最后一人保证总额守恒）；StateUpdate `op:'push'`+userIdExpr/amountExpr（贡献台账）；EffectType `mintShareVouchers`（GSO 逐人铸 RSV，share=amount/total）；currency 字段支持 `'expr: params.currency'`（resolveCurrency 枚举校验）
- **A币（aCoins）托管**：本地用 vouchers 文档直改（currentHolderId→contract-escrow:{id}+frozenAt）；云函数首发仅 gameCoins（A币托管 B5 接入时补）

## 踩坑（重要）
- **contracts 内部相对 import 必须带 .js 后缀**：tsconfig.server 输出 Node ESM，无后缀 ERR_MODULE_NOT_FOUND；.js 后缀与 vite/vitest/esbuild 全兼容（125 测试重跑全绿）
- **server.js 是 ESM**，import 路径 `./dist/server/server/routes/xxx.js`（双层 server 目录：tsconfig.server rootDir=src outDir=dist/server）
- **gameWallet adjust 端点 userId 以 token 为准**（body.userId 被忽略）——冒烟要用自己的 token 充自己的钱
- **内存 DB 磁盘持久化会恢复脏数据**：多轮冒烟必须 `MEMORY_DB_FILE=none`（或删 .data/memory-db.json）+ 按端口杀干净旧进程
- **timer trigger event 非 HTTP 形状**：main() 开头 `event.Type==='Timer'` → 伪装 POST /__contract/tick
- gameWallet balance 端点：`GET /platform/balance`（token 解析 userId）
