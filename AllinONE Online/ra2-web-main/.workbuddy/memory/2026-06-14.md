# 2026-06-14

## 项目初始化与环境配置
- 探索了 ra2-web 项目整体架构：
  - `packages/data` — RA2 文件格式解析器（MIX/INI/PAL/SHP/TMP/VXL/CSF/地图/音频）
  - `packages/game` — 确定性模拟内核（定点数学、确定性 PRNG、状态哈希、寻路）
  - `packages/client` — PixiJS v8 渲染 + Vite 构建 + 启动画面/Hash 路由
  - `packages/server` — Node + WebSocket 联机房间 + lockstep 指令转发
- 使用 npmmirror.com 镜像安装了所有 pnpm 依赖（共 172 个包）
- 使用 `pnpm --filter @ra2web/client build` 成功构建了客户端（Vite 生产构建）
- 使用 `pnpm --filter @ra2web/client dev` 启动 Vite 开发服务器，游戏可在 http://localhost:5173 运行
- 使用内置浏览器预览成功

## 关键技术细节
- Vite 开发服务器包含 game-data 插件（暴露 `/game-data/` 路径供读取原版 RA2 文件）和 witness-mock 插件（见证者计数 API）
- 游戏使用 Hash 路由：`#`（首页）、`#play`（单机）、`#mp`（联机）、`#assets`（素材浏览器）、`#map`（地图查看器）、`#sim`（模拟沙盒）
- 没有原版 RA2 文件时，游戏使用占位图（placeholder-art）模式运行

## 构建输出

### 方案A：独立文件夹（可双击运行）
- 修改 `packages/client/vite.config.ts`：
  - 添加 `base: './'`（所有资源路径改为相对路径）
  - 添加 `fixBuildHtmlPlugin`（post-transform 插件：去除 crossorigin、type="module"→defer、移除 manifest 链接）
  - 设置 `build.rollupOptions.output.format: 'iife'` + `inlineDynamicImports: true`（输出单个 IIFE 文件）
- 输出目录：`packages/client/dist/`，文件结构：1 HTML + 1 JS（689KB）+ bgm.mp3 + icon.svg
- 三轮迭代修复 file:// 兼容性：
  1. 相对路径 + 去 crossorigin（仍报 CORS，因 type="module"）
  2. IIFE 格式 + 去 type="module"（仍报 manifest CORS + innerHTML null）
  3. type="module"→defer + 移除 manifest 链接（✅ 最终修复）

### 方案B：单文件内联HTML
- 安装 `vite-plugin-singlefile` 处理 JS/CSS 内联
- 创建 `vite.singlefile.config.ts` 专用构建配置
- 创建 `scripts/inline-assets.js` 后处理脚本，将 bgm.mp3 / icon.svg / manifest.webmanifest 转为 base64 data URI 嵌入
- 添加 bgm.mp3 路径拦截补丁（替换动态加载的 `/bgm.mp3` 为内联 data URI）
- 输出文件：`packages/client/dist-singlefile/index.html`（8.5MB 单文件）
- 新增构建命令：`pnpm build:singlefile` / `pnpm build:all`
- 验证：file:// 协议通过内置浏览器预览成功
