# 2026-09-06 拼豆模拟器开发日志

- **按 AllinONE v3.0 指南重新接入平台**（指南：D:\AllinONE Gaming Platform\docs\allinone-publishing-guide.md）。
  v3.0 相对 v2.0 的核心变化：要求「可扩展性」——预留 slot 挂载点、开放内容创作 SOP、原版/扩展用 `?ext=` 严格隔离。

- **可扩展性改造（index.html）**
  - 图纸数据外置：PRESETS（爱心/笑脸/小花）保留为 base；新增 `extPatterns` 数组承接平台合并的社区图纸。
  - 内容应用函数：`a1gNormalizePattern(data)` 防御式兜底——支持 layout+legend 字符网格 与 grid 二维数组两种输入；颜色只接受 #rgb/#rrggbb（其余置空，可挡 `javascript:` 注入）；尺寸钳制 **2~59**（注意：最初写成 5~59 会把声明 3×3 撑成 5×5，已修正）；声明尺寸大于实际补空、小于则截断；全空图纸判无效。
  - 入口 UI：侧栏新增「社区图纸（扩展）」卡片区（id=extCard）+ 快速选择下拉框（id=extPatternSelect）；每张图纸渲染卡片，带 临摹/填充/挑战 + EXT 徽章 + 星级徽章。
  - 构建 API：`window.BeadLevel.build(api)`，api 暴露 setBead(c,r,hex)/rect/fill/grid/COLS/ROWS。
  - 游戏侧新增：`loadPattern(data, mode, sessionOnly)`（mode=trace|fill|challenge）、`setExtPatterns/getExtPatterns/patternInfo`（挂在 window.myGame）、`ensurePatternColors`（图纸用到调色板外颜色时自动注册为「扩展色」，否则 sprite 缺失会渲染成空白）、`suppressDraft` 标志（内容凭证按次生效，sessionOnly 时不写 localStorage 草稿）。

- **三段集成代码**：A 扩展加载器（slot=levels，`?ext=` 过滤、历史嵌套扁平化、脚本型用 Blob URL + `<script>` 非 eval、三级资源回退、失败降级原版）；B 内容工坊接收器（同时注册 AllinONE_ContentLoader.on + AllinONE_ContentHandlers + 监听 allinone:content-pack-applied 三重兜底，覆盖 loader 注入时序问题；levels=图纸、items=配色包）；C 道具双通道（v2.0 已完成，本次沿用）。

- **新增交付物**：`allinone-content-sop.json`（enabled:true，levels 图纸 / items 配色包 / skins 熨烫纹理，含内嵌 sopDocument）、`content-creation-guide.md`（喂给玩家 AI 的创作指南）、`task-dev-guide.md`（7 节《任务开发说明》，不含源码）；重写 `allinone-publish-config.txt`（加内容 SOP、4 个种子任务、完整检查清单、控制台自测技巧）。
