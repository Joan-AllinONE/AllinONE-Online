零、v3.0 可扩展性改造（已完成）
--------------------------------------------------
改造 1 · 内容数据外置
  原版图纸仍内置为 PRESETS（爱心 / 笑脸 / 小花，无 _submissionId，属于 base）；
  新增 extPatterns（数组），由平台把玩家提交的内容包逐条展开追加进来。
  读取统一走 window.myGame.getExtPatterns()。

改造 2 · 内容应用函数（防御式兜底）
  a1gNormalizePattern(data)：
    · 支持两种输入：layout + legend 字符网格，或 grid 二维数组
    · 颜色只接受 #rgb / #rrggbb，其余（red / #GGG / javascript:...）一律置空
    · 尺寸钳制 2~59；声明大于实际则补空，小于则截断
    · 全空图纸判定无效并返回 null
    · 使用调色板以外的颜色时，游戏自动注册为「扩展色」加入调色板
  a1gApplyPattern(data, mode, sessionOnly)：mode = trace / fill / challenge

改造 3 · 玩家可见的入口 UI
  侧栏新增「社区图纸（扩展）」卡片区 + 右上角快速选择下拉框；
  每张图纸渲染为卡片，带 临摹 / 填充 / 挑战 三个按钮与 EXT 徽章、星级徽章。

改造 4 · 构建 API
  window.BeadLevel = { build: function(api){} }
  api 暴露：setBead(c,r,hex) / rect(x0,y0,x1,y1,hex) / fill(hex) / grid / COLS / ROWS

铁律 · 原版与扩展隔离
  无 ?ext=  → 只保留无 _submissionId 的条目（纯净原版）
  有 ?ext=  → 原版 + 该 submissionId 的条目（并自动在下拉框选中）


--------------------------------------------------
一、Skills 推荐
--------------------------------------------------
游戏类型：休闲 / 创意工具（拼豆模拟器）

  [必选] auth         玩家登录与身份，个性化（收藏/进度/凭证归属）的基础
  [必选] wallet       道具交易与 ACOIN 结算、任务悬赏报酬发放
  [推荐] inventory    管理玩家获得的 UGC 道具与兑换道具库存（对应底部 PROPS 栏）
  [推荐] achievements 图纸挑战 1~3 星成就、创作里程碑展示

说明：本作为纯前端单机创作工具，「我的收藏」存于 localStorage；
      若后续接入云端收藏，再补 store / cloudstore。


--------------------------------------------------
二、兑换道具配置
--------------------------------------------------
| 名称         | 效果类型       | 参数                         | 价格(ACOIN) |
|--------------|----------------|------------------------------|-------------|
| 新手礼包     | rainbow_fill   | {}                           | 0（免费）   |
| 一键填充券   | instant_fill   | {"charges":3}                | 20          |
| 创意加速包   | scatter_beads  | {"count":30,"hex":"#ff8c1a"} | 30          |
| 大师熨烫券   | instant_iron   | {"effect":"glossy"}          | 50（×3）    |

描述示例：
- 新手礼包：新玩家一键获得一幅彩虹拼豆图，快速体验完整流程。
- 一键填充券 ×3：填充图纸是付费能力，需消耗填充券才能「一键填充」，归零后自动锁定——核心付费点。
- 创意加速包：随机撒上 30 颗橙色豆，灵感起手不卡壳。
- 大师熨烫券 ×3：跳过 80% 覆盖判定直接熨烫定型，省去繁琐步骤。

三、道具 SOP 速查（详见 allinone-sop.json）
--------------------------------------------------
- schemaName:        bead-studio-item
- availableEffects:  instant_fill / rainbow_fill / clear_board / instant_iron /
                     unlock_symmetry / unlock_color / scatter_beads / reveal_reference
- effectCodeEnabled: true（沙箱注入 window.myGame，可用 game.rainbowFill() 等）
- presetItems:       一键填充券 / 彩虹铺豆 / 清板符 / 大师熨烫券 / 对称结晶 / 灵感喷射

七、本地自测技巧（浏览器控制台）
--------------------------------------------------
1. 模拟平台下发道具：
   window.dispatchEvent(new CustomEvent('allinone:item-redeemed',
     { detail: { itemId: 'instant_fill', itemName: '一键填充券',
                 voucherData: { params: { charges: 3 } } } }));

2. 直接授予填充券：
   window.myGame.grantFill(3)

3. 模拟内容凭证图纸（本次会话生效，不写存档）：
   window.AllinONE_ContentHandlers.levels({
     name: '测试小猫',
     data: { id:'t1', title:'测试小猫', cols:9, rows:9,
             legend:{ '.':null, 'K':'#3a3a4a', 'P':'#ffb3c6' },
             layout:['.........','..K...K..','..KK.KK..','.KKKKKKK.',
                     '.KKKPKKK.','.KKKKKKK.','..KKKKK..','...KKK...','.........'] }
   });

4. 查看当前图纸统计：
   window.myGame.patternInfo()   → { base: 3, ext: N, cols, rows }
