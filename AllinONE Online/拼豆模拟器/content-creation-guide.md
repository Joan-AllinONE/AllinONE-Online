# 豆趣工坊·像素熨斗 —— 内容创作指南

> 这份文档会作为上下文喂给创作玩家的 AI。**你写得越具体，AI 产出的图纸质量越高。**
> 本指南只公开接口与数据格式，不含任何游戏源码。

---

## 一、游戏简介

《豆趣工坊·像素熨斗》是一款拼豆（熔珠 / fuse bead）模拟器。

**核心循环**：选图纸 → 夹豆摆放 → 熨烫定型 → 收藏 / 导出。

**玩法**：在网格画布上点击或拖拽放置彩色圆豆，画满后点「🔥 熨烫定型」，豆子融合成平整成品（光面 / 毛巾 / 灯芯绒 / 磨砂四种效果），然后收藏或导出 PNG。

**操作**：单击或拖拽填色 · 右键 / 长按擦除 · 吸管取色 · 对称轴（水平 / 垂直 / 中心）· 撤销重做。

**三种模式**（每张图纸都支持）：

| 模式 | 说明 |
|---|---|
| 临摹 | 空白画布 + 半透明彩色提示，照着填 |
| 填充 | 一键铺满整张图纸（需消耗「一键填充券」道具） |
| 挑战 | 计时 + 进度条 + 闪烁提示格，按用时评 1~3 星 |

## 二、你能创作什么

| 类型 | 挂载点 slot | 模式 | 难度 | 说明 |
|---|---|---|---|---|
| 拼豆图纸 | `levels` | data / inject | ★ ~ ★★★★ | 最推荐，见下方格式 |
| 配色包 | `items` | data | ★ | 一组主题颜色，载入后加入调色板 |
| 熨烫纹理 | `skins` | inject | ★★★ | 自定义熨烫后的表面质感（进阶） |

**图纸尺寸建议**：

| 尺寸 | 难度 | 适合画什么 |
|---|---|---|
| 13×13 | ★ 入门 | 水果、表情、简单图标 |
| 21×21 | ★★ 普通 | 小动物、食物、道具 |
| 29×29 | ★★★ 进阶 | 像素角色、场景 |
| 43×43 / 59×59 | ★★★★ 硬核 | 精细插画、名画像素化 |

## 三、拼豆图纸数据格式（重点）

### 3.1 字符网格格式（推荐，最省体积、最好手写）

```json
{
  "id": "cat",
  "title": "小猫",
  "difficulty": "普通",
  "cols": 13,
  "rows": 13,
  "legend": {
    ".": null,
    "K": "#3a3a4a",
    "W": "#ffffff",
    "P": "#ffb3c6"
  },
  "layout": [
    ".............",
    "..K.......K..",
    "..KK.....KK..",
    "..KKKKKKKKK..",
    "..KWKKKKKWK..",
    "..KKKKPPPKK..",
    "..KKKKKKKKK..",
    "...KKKKKKK...",
    "....KKKKK....",
    "............."
  ]
}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | 否 | 唯一标识，建议英文小写，如 `cat`；不填则用 title |
| `title` | **是** | 图纸名称，会显示在卡片上 |
| `cols` / `rows` | 否 | 网格宽高，2~59；不填则按 layout 自动推算 |
| `legend` | 与 layout 搭配**必填** | 字符 → 颜色的映射表 |
| `layout` | 与 grid 二选一 | 字符串数组，每行一个字符串 |
| `grid` | 与 layout 二选一 | 二维数组：`[["#ff0000", null], ...]` |
| `difficulty` | 否 | 自由文本，仅作展示 |
| `script` | 否 | 脚本型图纸入口，见 3.3 |

### 3.2 规则与兜底（重要）

- `.` 以及 legend 中未登记的字符 = **空格**（不放豆）。
- 颜色**只接受** `#rgb` 或 `#rrggbb`（大小写均可）。写成 `red`、`#GGG`、`javascript:...` 都会被当作空格丢弃。
- 尺寸超出 2~59 会被**钳制**；声明尺寸大于实际内容会**补空**，小于则**截断**。
- **至少要有 1 颗豆**，全空图纸会被直接拒绝。
- 每行字符数不一致时，按最长行补空对齐。
- 使用调色板以外的颜色也完全可以——游戏会自动把它注册为「扩展色」加入调色板。

### 3.3 脚本型图纸（程序化生成）

当图案需要程序化生成（对称雪花、渐变波纹、分形）时，改用脚本：

```json
{
  "id": "snowflake",
  "title": "六角雪花",
  "cols": 21,
  "rows": 21,
  "script": "js/snowflake.js"
}
```

`js/snowflake.js` 内容示例：

```js
window.BeadLevel = {
  build: function (api) {
    // api.ROWS / api.COLS   网格尺寸
    // api.setBead(c, r, hex) 在 (列 c, 行 r) 放一颗豆
    // api.rect(x0, y0, x1, y1, hex) 填充矩形
    // api.fill(hex)         整版填充
    // api.grid              二维数组引用，可直接读写
    var mid = Math.floor(api.COLS / 2);
    api.fill('#cfe8ff');
    for (var i = 0; i < api.COLS; i++) {
      api.setBead(i, mid, '#4a90d9');
      api.setBead(mid, i, '#4a90d9');
      api.setBead(i, i, '#4a90d9');
    }
  }
};
```

> 脚本以 `<script>` 标签方式加载执行（非 eval）。请**不要**在其中访问网络、读写 localStorage 或操作 DOM——这类代码会被平台扫描拦截。

## 四、配色包格式

```json
{
  "colors": [
    { "name": "奶油杏", "hex": "#ffd8b1" },
    { "name": "雾霾蓝", "hex": "#8fb8de" },
    { "name": "抹茶绿", "hex": "#b5d9a8" }
  ]
}
```

也可直接给字符串数组：`["#ffd8b1", "#8fb8de", "#b5d9a8"]`。建议 4~12 色。

## 六、资产打包规范

- 内容包结构：`{ type, slot, name, description, data, assets[] }`
- `assets[].path` 用**相对路径**，如 `js/snowflake.js`、`bg.png`
- 二进制文件（图片 / 音频）用 base64 并加前缀 `__BINARY_BASE64__`
- 单资产 ≤ 8MB，整包 ≤ 20MB，任务提交单文件默认 ≤ 512KB
- 脚本里引用资源直接写相对路径，游戏会自动做三级回退解析

---

## 七、安全与版权约束

- 颜色字段只接受 `#` 开头十六进制值，任何脚本写法都会被丢弃。
- 禁止提交访问网络、读写本地存储、操作 DOM 的代码。
- 禁止提交受版权保护的商业 IP 形象（动漫角色、品牌 Logo 等）作为图纸内容。
- 注入型内容（熨烫纹理）由平台直接注入，游戏侧**不提供**专门的纹理 API，请勿依赖任何游戏内部变量。

## 八、让 AI 帮你画图纸的提示词模板

把下面这段连同你的想法一起发给 AI：

```
我要为《豆趣工坊·像素熨斗》创作一张拼豆图纸。

【输出格式】只输出 JSON，不要解释
{
  "id": "英文标识",
  "title": "图纸名称",
  "cols": 21,
  "rows": 21,
  "legend": { ".": null, "A": "#rrggbb", "B": "#rrggbb" },
  "layout": [ ".....", "..A..", ... ]
}

【规则】
- '.' 表示空格；其余字符必须在 legend 里登记为 #rrggbb 颜色
- cols/rows 取值范围 2~59，每行长度必须一致（用 '.' 补齐）
- 至少要有 1 个非 '.' 的格子
- 颜色尽量从内置 16 色里选：#e63946 #ff8c1a #ffd23f #4caf50 #36c2b4
  #4cc9f0 #3a86ff #8b5cf6 #ff8fb1 #a0714f #ffffff #3a3a4a #d9d9e3 #8a8a9a #ffe8c9 #ff5d8f
- 图案要有清晰轮廓，色块尽量成片，避免孤立单像素

【我要画的是】：（在这里描述，例如「一只戴帽子的小猫，21×21，粉色系」）
```
