# 缅川公盘 · 任务开发说明

> 本文档是接单玩家与玩家 AI 的唯一依据。只公开接口与数据格式，不含任何游戏源码。

## 一、游戏简介

《缅川公盘》是网页版翡翠赌石模拟游戏（纯虚拟玉币，无真实资金）。

- **玩法**：用玉币在矿区买原石 → 相玉（强光手电照种水区间）→ 解玉（**擦皮**三段揭晓可中途收手，或**一刀切**直接开）→ 按实时浮动行情（0.8~1.5 倍 K 线）出售，或送**加工坊**切成手镯/玉牌/平安扣/戒面/玉珠
- **操作**：纯鼠标/触屏点击，无键盘需求；3D 原石可拖拽 360° 观赏
- **成长**：解玉攒经验晋升爵位（学徒→掌眼→大藏家→玉侯→玉皇），爵位解锁更高级矿区

## 二、你能为这个游戏做什么

| 任务类型 | 难度 | 挂载点 slot | 说明 |
|---|---|---|---|
| 新矿区（数据型） | ★☆☆ | `levels` | 设计一个场口：起价/出绿率/种水权重/封顶/皮壳外观，合并后永久上线给所有玩家 |
| 新矿区（进阶平衡向） | ★★☆ | `levels` | 复刻真实场口（莫西沙/后江/会卡…），要求期望回值 95%~105%，需附平衡计算说明 |

道具/皮肤/脚本类任务暂未开放，敬请期待。

## 三、通用约定

1. 玩家产物是 **ContentPack 内容包**，追加到游戏声明的挂载点，不做源码合并
2. assets 相对路径需与 data 内引用一致（本游戏矿区任务不需要 assets）
3. 内容**审核合并后才生效**；带 `?ext=<submissionId>` 打开可单独体验你的矿区，不带则是纯净原版
4. 安全与版权：禁止违规文案；矿区名/介绍请自拟，勿抄他人提交

## 四、游戏方开放的接口

### 矿区数据字段表（slot: levels, type: map）

| 字段 | 必填 | 约束（超限自动夹取） | 说明 |
|---|---|---|---|
| `id` | 建议 | `[A-Za-z0-9_-]`，≤20 字符 | 唯一标识，冲突自动改 |
| `name` | ✅ | ≤10 字 | 矿区名 |
| `icon` | 可选 | 1 个 emoji | 默认 ⛰️ |
| `lv` | 可选 | 1~60 | 解锁爵位等级，默认 1 |
| `price` | ✅ | 50~10,000,000 | 原石起价（玉币） |
| `green` | ✅ | 0.02~0.6 | 出绿概率（0.2=20%，支持百分制） |
| `cap` | 可选 | ≥price×1.5，≤5,000,000 | 极品封顶，默认 price×10 |
| `skin` | 可选 | dark/brown/white/wax 或 1~4 | 皮壳底版（影响 3D 外观） |
| `skinName` | 可选 | ≤8 字 | 皮壳显示名 |
| `desc` | 可选 | ≤40 字 | 矿区介绍 |
| `w` | 建议 | `[[种水id,权重],...]` | 出绿后种水分布；种水id：`dou`/`nuo`/`bing`/`boli`/`diwang` |

内置矿区参考（请勿照抄）：黑乌沙 price500/green0.25/cap5000；帝王场 price50000/green0.05/cap5000000。

### 道具效果表（道具类任务暂未开放，仅作参考）

| effect | 参数 | 效果 |
|---|---|---|
| `add_coins` | `bonus` 500~50000 | 增加玉币 |
| `flash_plus` | `times` 1~9 | 补充强光手电次数 |
| `lucky_cut` | `cuts` 1~9 | 接下来 N 块石头出绿率 ×1.6 |
| `market_up` | `mult` 1.1~1.5, `seconds` 15~600 | 行情拉升并冻结 |

## 五、让 AI 帮你完成任务的提示词模板

```text
你是《缅川公盘》（翡翠赌石模拟游戏）的矿区设计师。请按以下规范设计一个新矿区，输出 ContentPack JSON。

要求：
- 矿区名：{你的创意，如"后江场口"}
- 定位：{如"中档稳中带赌，主出糯冰"}
- 数据约束：price 50~1000万；green 0.02~0.6；cap ≥price×1.5；w 的种水id只能是 dou/nuo/bing/boli/diwang，diwang 权重≤8（千分制）；期望回值须在 95%~105%
- 输出格式：
{
  "type": "map",
  "slot": "levels",
  "name": "矿区名≤10字",
  "description": "一句话简介",
  "data": { "id": "英文小写下划线", "name": "...", "icon": "一个emoji", "lv": 1~60, "price": 数字, "green": 小数, "cap": 数字, "skin": "dark|brown|white|wax", "skinName": "≤8字", "desc": "≤40字", "w": [["dou",权重],...] }
}
请先给出平衡性计算（各档期望收益），再输出 JSON。
```

> ⚠️ 提交时**只取其中 `data` 字段的内容**粘进任务提交框的 data 框（单个矿区对象即可），不要粘整个 ContentPack——平台会自动包装，详见第六节。

## 六、提交格式与步骤

1. 按第四节字段表填写矿区对象（不需要 assets 与 entryPoint）
2. ⚠️ 任务提交框的 **data 框只粘贴 `data` 字段的内容**：单个矿区对象（推荐）或矿区数组均可，平台会自动包装成 ContentPack。不要把 `{ "type": "map", "slot": "levels", ... }` 整包粘进去——整包会被当成矿区数据本身，校验不通过
3. 提交前自检：
   - [ ] 粘贴的是矿区对象/数组，而不是整个 ContentPack
   - [ ] price/green/cap 数值在约束内
   - [ ] w 权重为正数且含至少 2 个种水档
   - [ ] 矿区名与内置四矿区不重复（黑乌沙/大马坎/木那/玻璃种帝王场）
   - [ ] 已附平衡性说明（进阶任务）
4. 提交后等待审核（开发者直审）→ **审核通过后必须再点「合并」才生效** → 打开游戏页右上角「扩展」菜单进入你的矿区（数据型扩展合并后自动出现在菜单，或带 `?ext=` 打开）

## 七、常见问题

**Q：green 填 20 还是 0.2？**
A：都行，>1 的值自动按百分制除以 100，最终夹取到 0.02~0.6。

**Q：我的矿区会被锁定吗？**
A：`lv` 字段控制解锁爵位等级；不填默认 Lv.1 全员可玩。

**Q：为什么我的矿区 id 变了？**
A：与内置矿区或已合并内容冲突时自动改生成 id，功能不受影响。

**Q：可以直接给 `w` 里塞 100 个 diwang 吗？**
A：会被归一化，且平台校验会拦截明显失衡的分布；请按第五节守则设计。

**Q：矿石的 3D 外观由什么决定？**
A：`skin` 字段选皮壳底版（黑乌沙漆皮/黄砂水石/白盐沙/腊壳），纹理细节程序化生成，每块石头都不同。
