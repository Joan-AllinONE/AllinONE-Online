# 缅川公盘 · 矿区创作指南

> 本文档会自动作为上下文喂给内容工坊玩家的 AI。按此规范产出的矿区数据包可直接铸成内容凭证使用。

## 一、玩法说明（30 秒懂）

《缅川公盘》是翡翠赌石模拟游戏：玩家用虚拟玉币买原石 → 相玉（看皮壳/蟒带/松花/开窗）→ 解玉（擦皮或一刀切）→ 按浮动行情出售，或送加工坊切成手镯/玉牌。核心乐趣是"一刀穷一刀富"。

**矿区**就是风险的化身：每个矿区决定原石的起价、出绿率、能出多好的货、封顶多高的价值。你创作的矿区会出现在游戏矿区页，标注 🧩 玩家矿区。

## 二、矿区数据结构（data 字段表）

```json
{
  "id": "mayang_keng",
  "name": "莫西沙场口",
  "icon": "🏔️",
  "lv": 8,
  "price": 3000,
  "green": 0.2,
  "cap": 80000,
  "skin": "white",
  "skinName": "脱砂皮",
  "desc": "脱砂见底的好场口，种水到冰是常态。",
  "w": [["dou",30],["nuo",30],["bing",25],["boli",12],["diwang",3]]
}
```

| 字段 | 必填 | 约束（超限自动夹取） | 说明 |
|---|---|---|---|
| `id` | 建议 | 字母/数字/下划线，≤20 字符 | 与内置矿区冲突时自动改生成 id |
| `name` | ✅ | ≤10 字 | 矿区显示名 |
| `icon` | 可选 | 1 个 emoji | 默认 ⛰️ |
| `lv` | 可选 | 1~60 | 解锁爵位等级（学徒1/掌眼10/大藏家20/玉侯40/玉皇60），默认 1 |
| `price` | ✅ | 50 ~ 10,000,000 | 原石起价（玉币），实际标价按体型形状浮动 |
| `green` | ✅ | 0.02 ~ 0.6 | 出绿概率，`0.2`=20%；也接受百分制 `20` |
| `cap` | 可选 | ≥ price×1.5 | 极品价值封顶，默认 price×10 |
| `skin` | 可选 | `dark`/`brown`/`white`/`wax`（或 1~4） | 皮壳底版：黑乌沙/黄砂水石/白盐沙/腊壳蒙头料，影响 3D 外观 |
| `skinName` | 可选 | ≤8 字 | 皮壳显示名，如"脱砂皮" |
| `desc` | 可选 | ≤40 字 | 矿区介绍文案 |
| `w` | 建议 | 见下 | 出绿后的种水分布权重 |

**种水 id（w 可用值）**：`dou` 豆种 → `nuo` 糯种 → `bing` 冰种 → `boli` 玻璃种 → `diwang` 帝王绿。
权重为正数即可，系统自动归一化；非法项剔除；全部为空时给默认分布。

## 三、数值设计守则（务必遵守）

1. **期望回值 95%~105%**。参考内置四矿区的"出绿率 × 封顶"互补设计：
   - 黑乌沙场口：green 25%，cap 5,000（高频小赚）
   - 帝王场：green 5%，cap 5,000,000（低频暴富）
2. `cap / price` 比值 = 最大单刀倍数，越大越"赌"。
3. `w` 中 `diwang` 权重建议 ≤8（千分制 8/1000），否则产出失衡。
4. 禁止设计"稳赚矿区"（如 green>50% 且 cap>price×20）——平台与游戏侧都会夹取。

## 四、安全约束

- 只接受**数据型**内容包（`modes: ["data"]`），不接受任何脚本
- 玩家矿区在游戏内明确标注「🧩 玩家矿区」，与官方矿区区分
- 所有数值经服务端校验 + 游戏侧防御式兜底（缺失补默认、超限夹取、id 去重）
